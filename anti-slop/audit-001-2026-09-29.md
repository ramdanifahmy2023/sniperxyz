# Audit alur rekaman Sniper

29 September 2026. Review berbasis source, sebagai bagian audit kelengkapan data. Tidak ada perubahan UI. Kontras, mobile, tema, dan keyboard secara runtime belum diverifikasi.

1. **HIGH, R-27 dan C-5:** `popup.js:137–169` menampilkan Audit aktif berdasarkan flag lokal, sementara status queue diambil sekali dan kesalahan penghentian sesi ditelan. Pengguna belum dapat membedakan collector aktif, data tersimpan, dan server gagal. Usulan: status terpisah, last ACK, alasan kegagalan, dan tindakan coba lagi.

2. **HIGH, R-27:** `content.js:15–23` tidak menggunakan hasil `{queued:false, reason}`; `background.js:309` hanya menyediakan hitungan queue. Data yang tidak masuk rekaman belum memiliki penjelasan di alur pengguna. Usulan: diagnostic reason terstruktur dan tampilan data dilewati/ditolak, tanpa menyebut semua kehilangan dapat diketahui collector.

3. **HIGH, R-38 dan C-5:** `Panel.php:92,110,130` membatasi sesi/timeline/ekspor tanpa memberi status kelengkapan pada halaman atau file ekspor. Usulan: pagination, jumlah hasil, penanda belum lengkap, dan ekspor seluruh halaman dengan manifest.

4. **HIGH, R-32:** `views/panel/payloads.php:114` membuka screenshot melalui `onclick` pada elemen `img` tanpa kontrol keyboard. Usulan: jadikan thumbnail sebuah button berlabel dan kembalikan fokus setelah dialog ditutup. Kondisi ini hanya berlaku bila ada screenshot pada payload.

5. **LOW, C-3 dan R-31:** `views/panel/session.php` menampilkan daftar request tanpa drilldown event, konteks filter, atau kaitan angka dashboard. Untuk tugas membaca angka Shopee, keputusan utama pengguna adalah memastikan angka/periode/sumber benar. Usulan: detail metrik dan bukti yang dapat dibuka dari timeline, mempertahankan struktur UI yang sudah ada.

Rekomendasi di atas belum diimplementasikan. Tidak dilakukan perubahan dekoratif atau klaim desain telah lolos pemeriksaan runtime.
